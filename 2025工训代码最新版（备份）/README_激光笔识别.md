# 激光笔识别功能使用说明

## 概述
已将原来的 `laser_find.py` 中的激光笔识别功能封装成函数，并集成到主程序 `main.py` 中，方便调用不同的识别模式。

## 文件结构

### 1. laser_find.py
- **功能**: 包含激光笔识别的核心函数
- **主要函数**: 
  - `laser_detection_mode()`: 激光笔识别主函数
  - `main()`: 独立运行时的主函数

### 2. main.py (已修改)
- **新增功能**: 集成了激光笔识别模式
- **修改内容**:
  - 导入了 `laser_detection_mode` 函数
  - 添加了 `laser_wrapper` 包装函数
  - 在函数字典中添加了 `"laser_detect"` 模式
  - 在主循环中添加了激光笔识别分支

### 3. mode_selector.py (新增)
- **功能**: 模式选择器，用于切换不同的识别模式
- **特点**: 提供友好的菜单界面

## 使用方法

### 方法一：通过 main.py 使用
1. 修改 `global_vars.mode` 的值为 `"laser_detect"`
2. 运行 `main.py`

```python
# 在 main.py 中或其他地方设置
global_vars.mode = "laser_detect"
```

### 方法二：使用模式选择器
1. 运行 `mode_selector.py`
2. 选择 "4. 激光笔识别模式"
3. 然后运行 `main.py`

```bash
python mode_selector.py
python main.py
```

### 方法三：直接运行激光笔识别
```bash
python laser_find.py
```

## 激光笔识别原理

### 技术方案
- **帧差法**: 通过比较连续两帧图像的差异来检测运动的激光点
- **二值化处理**: 将差异图像转换为黑白图像，突出激光点
- **形态学处理**: 使用膨胀操作强化激光点特征
- **轮廓检测**: 找到激光点的轮廓并计算中心坐标

### 关键参数
- **阈值**: 25 (用于二值化，高于此值认为是运动)
- **最小轮廓面积**: 200 (小于此值当作噪点过滤)
- **膨胀核**: 5x5矩形核，迭代2次

### 输出信息
- 激光点的统计值和轮廓面积
- 在图像上绘制蓝色十字标记激光点位置

## 注意事项

1. **环境要求**: 需要相对暗的环境以便更好地检测激光点
2. **激光笔颜色**: 代码中有针对绿色激光笔的特殊处理
3. **运动检测**: 激光点需要有一定的移动才能被检测到
4. **退出方式**: 按 Ctrl+C 退出程序

## 故障排除

### 检测不到激光点
1. 检查环境光线是否过强
2. 确认激光笔是否在移动
3. 调整二值化阈值 (当前为25)
4. 检查最小轮廓面积设置 (当前为200)

### 误检测问题
1. 增大最小轮廓面积阈值
2. 调整二值化阈值
3. 检查环境中是否有其他移动物体
